# 从会运行到能解释

这个仓库的学习目标，是把“我跑出了结果”推进到“我知道为什么能信、哪里还不能信”。

## 先用五分钟读结果

1. 打开 [样例报告](sample/REPORT.md)，找出信用候选与上一季基线的留出期 MAE。
2. 用自己的话解释：为什么最高训练 R² 不能决定最终选择。
3. 找出被信息可得性检查拒绝的模型；解释它的低误差为什么没有意义。
4. 看 FX bump 图，解释为什么步长越小不一定越准确。
5. 查单位表：20% 波动率怎么输入？Vega 的原始偏导和每一个波动率百分点有什么区别？

## 做三个可以检验的练习

| 练习 | 先作预测 | 再核实 |
|:--|:--|:--|
| 换一个固定种子 | 哪个模型更稳？基线会不会更好？ | 重跑并保留完整结果，不能只保留最好的一次 |
| 修改第 75 季以后的原始观测 | 哪些预测时点的特征应该保持不变？ | 阅读并运行未来数据扰动测试 |
| 调整差分步长 | 哪个区间主要是截断误差，哪个区间开始抵消？ | 比较全部 bump，解释单位和容差 |

## 两分钟项目讲法

“我做了一个独立的模型验证实验，所有输入都是自造的。信用部分先定义预测时点，
只使用此前可得的信息，再用向前切分选模、留出期评估，并保留简单基线。
期权部分从公开公式实现价格和敏感度，再用恒等式、量纲和价格差分检查。
最有价值的发现不是分数本身，而是哪些错误仍然可能通过某一种检查。
这些实验说明了实现与验证思路，还不能证明真实市场适用性或生产可用性。”

使用这段讲法前，应能不看答案讲清楚上述五个问题，并亲自修改、运行至少一个实验。
AI 辅助生成的代码本身不等于已经掌握；能解释假设、追踪错误和复现证据才是学习目标。
