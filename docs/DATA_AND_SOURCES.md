# Data and source declaration

This repository starts with its own Git history. It is not a sanitized export of a work repository.

| Material | Origin | What it represents |
|:--|:--|:--|
| Python implementation and tests | Newly written for this repository with AI assistance | Educational implementation and validation experiments |
| Credit inputs | Seeded generator in `credit.py` | Invented macro indices and binomial default counts |
| FX scenarios | Explicit constants in `fx.py` | Fictional FOR/DOM contracts, never sampled from transactions |
| Sample CSVs, JSON, charts | Generated by `report.py` | Reproducible experiment evidence |
| Equations and statistical methods | Linked public papers and official library documentation | General mathematical and numerical background |

No private files, internal templates, employer/client source code, licensed vendor output,
transaction identifiers, correspondence, workbook screenshots or confidential results are incorporated.
Synthetic does not mean anonymized, perturbed or resampled private data here: the mechanism is invented.

The implementation uses NumPy, pandas, SciPy, scikit-learn and Matplotlib; their respective licenses
continue to apply to those dependencies. Public method references appear in the FX and credit notes.
No third-party code is vendored. The MIT license covers this repository's original code and documentation.

Before a new contribution is published, review staged paths and content, prove the origin of new data,
rerun tests and the report, and check that the README's claims match the actual output. Automated
secret scanning helps detect credentials but cannot certify rights or confidentiality on its own.
